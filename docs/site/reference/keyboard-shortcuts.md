## These docs

| Key | Does |
|---|---|
| `/` | Jump to the search box |
| ↑ / ↓, Enter | Move through the search results, open one |
| Esc | Close the results or the navigation drawer |

## 1D view

The 1D view has no page-wide shortcuts, so it never steals your typing.

| Where | Key | Does |
|---|---|---|
| Any window | Esc | Close it |
| Ask the Project Coordinator | Enter · Shift+Enter · ↑ / ↓ | Send · new line · recall what you sent |
| The console's Chat / Terminal toggle | ← / → (Tab to it first) | Switch between the conversation and the terminal |
| View dropdown | ↑ ↓ Home End · Enter / Space · Esc | Move · pick · close |
| PR window | j / n, k / p, v | Next, previous, view |
| Changes window | j / k | Next, previous file |
| A terminal | Ctrl+Space | Dictate (hold and talk) |
| A terminal | Ctrl+[ | Send Esc to the terminal |

## 2D view

| Key | Does |
|---|---|
| N | Next worker that needs you |
| T | Chat |
| + / = · − · 0 | Zoom in · out · fit |
| Arrows | Pan |
| Esc | Close the menu |

## 2D Overview (home)

Wheel to zoom, drag to pan, **+ − 0** and the arrows.

| O | Open its pull request |
