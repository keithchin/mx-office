The **3D office** is the original Agent Office: a cartoon building you walk around in, with desks, boards, a meeting room, an elevator, a garage and a rooftop bar. **Retro** draws the same world in chunky 16-bit pixels.

Open it from the 3D office's own view dropdown, or go to `/?3d=1&view=3d` (or `view=retro`).

> [!TIP]
> For daily project work, use 1D or 2D: they show more and need no GPU. 3D is great for demos and for voice and the whiteboard together.

## Main controls

| Key | Does |
|---|---|
| W A S D | Walk (Shift to run) |
| Mouse | Look around (click to capture, Esc to free) |
| E / click | Use what you look at: a desk, a board, the elevator |
| N | Go to the next worker that needs you |
| P | Give a task to the worker at the desk you face |
| C | See what that worker changed |
| T | Chat |
| V | Join voice (hold to talk) |
| Ctrl+K | Command palette |
| Tab | The ☰ menu |
| H | All controls |

The full list is in the game's **❓ Controls** window and on [Keyboard shortcuts](../reference/keyboard-shortcuts.md).

## Graphics

- `?gfx=low|medium|high` sets quality (high is the default). Low has no antialiasing, shadows or outlines.
- On a laptop with two GPUs, make the browser use the fast one. On the Taskforce laptop, Edge is already set to the NVIDIA GPU.

See [Office and browser problems](../troubleshooting/office-and-browser.md).
